Server authors want to run their golden cases from their own pytest suites without launching a
subprocess. Implement `check_server(server, cases)` in mcpcheck/inproc.py. `server` is a server
object built with the mcp SDK's high-level decorator API. Connect an MCP client session to it in
memory (no subprocess, no sockets), call every case's tool through that session, and return the
mismatches exactly as `check_command` in mcpcheck/stdio.py does over stdio (same comparison, same
order). Do not add dependencies. You can run the tests with `pytest`.
